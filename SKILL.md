# Asynchronous Future Barrier Joiner

## Description
Barrier synchronization coordinator collecting concurrent agent futures, resolving join-all conditions, and merging branch results.

## Compatibility
- MCP Version: 2025-12-11
- Python: >=3.10 (Standard Library only)
- Supported Platforms: Claude Desktop, Cursor, LobeChat, Smithery

## Tools
Refer to `client.py` and `mcp_server.py` for full JSON-RPC tool signatures.
